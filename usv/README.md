# Volet USV

Objectif : assembler de manière pérenne les composants du drone et rendre opérationnelle l'exécution de missions préprogrammées (waypoints).

- [assemblage](assemblage) : schéma d'assemblage, inventaire des composants, manques identifiés
- [motorisation](motorisation) : choix et validation de la motorisation
- [missions](missions) : missions préprogrammées par waypoints
