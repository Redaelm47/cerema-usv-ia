## Comment on fonctionne

Depuis l'[atelier 6 de co-développement](../docs/plan_actions_USV-IA.pdf) du 05/11/2026 :

- **8h30**, point de début à six : ce qui a été fait depuis la dernière séance, ce qui bloque ;
- **11h40**, point de fin à six : qui fait quoi pour la séance suivante ;
- après chaque séance, le point de fin est résumé ici (action A8) ;
- les tâches vivent sur le tableau GitHub du dépôt (une tâche = une issue).

## Écrire un compte rendu

1. Copier le bon modèle :
   - [modele_point_de_seance.md](modele_point_de_seance.md) pour un point de fin de séance ;
   - [modele_compte_rendu.md](modele_compte_rendu.md) pour une réunion avec le Cerema ou les tuteurs.
2. Le nommer `AAAA-MM-JJ_objet.md`, par exemple `2026-11-12_point-de-seance.md`.
3. Ajouter sa ligne en haut du tableau ci-dessus et mettre à jour « Dernier en date ».

Les sources LaTeX des comptes rendus en PDF sont dans [sources/](sources).
